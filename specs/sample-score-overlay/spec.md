# Spec

## 基本信息

- 功能名称：Sample 分数居中覆盖
- 对应 Proposal：`specs/sample-score-overlay/proposal.md`
- 当前状态：approved
- 最后更新：2026-06-20

## 问题定义

Normal sample 外围格子方案需要回退，同时 samples 的分数文本应从图片下方移动到图片中心覆盖，以减少每个示例在右侧区域占用的高度。

## 用户故事

- 作为：游戏玩家
- 我希望：sample 分数直接显示在示例图中心
- 从而：右侧 samples 更紧凑，不需要额外占用一行文字空间

## 功能行为

### 主流程

1. `SampleRenderer.drawSample` 只按 blocks 原始边界渲染 sample 图片。
2. `GameSampleCanvas` 继续使用与主棋盘相同的 `cellSize` 生成 sample 图片。
3. 每个 sample 卡片使用相对定位。
4. 分数文本使用绝对定位覆盖在图片中心。
5. 图片保持自然尺寸，不通过 CSS 缩放。

### 异常流程

1. 如果分数较长，分数标签保持单行并居中覆盖。
2. 如果右侧空间不足，samples 仍通过 flex wrap 和右侧面板滚动承载。

### 空状态/加载态/错误态

- 加载态：samples 挂载前为空
- 空状态：不涉及
- 错误态：不涉及
- 重试机制：不涉及
